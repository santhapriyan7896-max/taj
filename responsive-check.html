Responsive check

Every frame loads the real index.html at a true device size and aspect ratio, from a folded phone at 320px to a 2560px ultrawide. Scroll inside any frame; the layout should reflow with no sideways scroll at any ratio.

Read the badge. Each frame runs a layout self-test and prints its result top-left. A green bar and ALL PASS means the leaf has real size, every dish is drawn and sized, the dish key matches the leaf, and nothing scrolls sideways. A red bar names the failing check. Scroll or resize and the badge re-measures.

The ratio is shown next to each size. Add a custom width to test anything not listed.
